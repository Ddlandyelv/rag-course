1按链路分组

术语按它在流水线上的位置分成四组。同一组内的词经常一起出现，记忆时可以按组记，比按字母顺序有效得多。

2基础

RAG
检索增强生成。提问时先从外部知识库检索相关片段，再连同问题一起交给模型生成答案。
朴素 RAG / Naive RAG
只做「分块→向量化→检索→拼提示」的最小实现，没有额外优化。
幻觉
模型生成看似合理但不符合事实的内容。机制上源于「输出概率上像样的续写」而非「核实事实」。
嵌入 / Embedding
把文本映射成固定长度向量，使语义相近的输入在空间中方向相近。
余弦相似度
两个向量夹角的余弦值，取值 −1 到 1。只看方向，不受向量长度影响。
上下文窗口
模型单次能处理的 token 上限。超出部分无法利用。
迷失在中间 / Lost in the Middle
资料越长，模型对开头与结尾的内容权重更高，中间部分容易被忽略。

3索引侧

ETL / 数据解析
从 PDF、Word、表格、网页中抽取文字与结构。是整条链路唯一不可逆的一步。
分块 / Chunking
把长文档切成适合检索的小片段。
chunk_size
单个片段的目标长度。中文场景常按字符计，起点 300–500 字。
overlap
相邻片段的重叠长度，保证被切断的句子至少在一块里完整。常取 10%–20%。
递归切分
按「段落 → 句子 → 词 → 字符」逐级降级切分。中文需显式加入「。！？；」等分隔符。
父子分块
小块用于检索匹配，命中后返回其所属的大块给模型。解耦检索精度与上下文完整性。
HNSW
基于图的近似最近邻索引，速度快、召回高、内存占用较大。
IVF / PQ
倒排索引 / 乘积量化。前者先聚类再局部搜索，后者压缩向量以省内存。

4检索侧

Top-K
取相似度最高的 K 条结果。通常会「大 K 召回 + 重排后取小 K」。
BM25
经典关键词检索算法，按词频与逆文档频率打分。对精确字符串敏感。
混合检索 / Hybrid Search
向量检索与关键词检索并行，再融合结果。
RRF
倒数排名融合。只用排名不用分数，避免两路分数量纲不一致。
RAG Fusion
把一个问题改写成多个查询分别检索，再用 RRF 融合。
重排 / Rerank
用交叉编码器对「问题 + 每条候选」逐条精算相关度，精度高但不能预计算。
Bi-encoder / Cross-encoder
分别编码 / 拼接编码。前者可预计算用于召回，后者精度高用于精排。
MMR
最大边际相关性。在相关性与结果多样性之间加权，缓解结果重复。
查询改写 / Query Rewriting
结合对话历史把指代、省略补全，使问句适合检索。
HyDE
先让模型编一个假答案，用假答案的向量去检索真文档。解决问句与文档形态差异。
上下文压缩
按句子相关度裁剪片段，减少无关内容占用上下文。

5架构与评估

Self-RAG
训练模型输出反思标记（要不要检索、资料相关吗、句子有依据吗、答案有用吗），用标记控制流程。
Graph RAG
抽取实体与关系建图，做社区检测与社区摘要，用局部查询/全局查询回答关系型与全局性问题。
社区摘要 / Community Summary
对一个聚类社区内所有实体关系生成的概述，用于全局查询的 map-reduce 汇总。
Agentic RAG
把知识库降级为工具之一，由智能体决定调什么、调几次。
Routing
按请求类型分发到不同处理路径（知识库 / 联网搜索 / 直接回复）。
多跳检索
上一轮的检索结果作为下一轮的查询输入，解决链式依赖问题。
上下文相关性
检索到的资料与问题相关的程度。低分说明检索环节有问题。
忠实度 / Faithfulness
答案的断言中有多少能由资料支持。只衡量「忠于资料」，不衡量资料是否正确。
答案相关性
答案是否正面回应了用户的问题。常用「从答案反推问题再比相似度」计算。
RAGAS
开源 RAG 评估框架，提供 context_precision / context_recall / faithfulness / answer_relevancy 四个指标。
LLM 裁判 / LLM as Judge
用强模型按给定标准批量打分。需先用人工标注的黄金集校准一致性。

本页要点

  1. 四组术语：基础概念、索引侧、检索侧、架构与评估。
  2. 索引侧的词决定「能不能查到」，检索侧的词决定「查得准不准」。
  3. 评估的三个指标分别对应检索、生成、端到端，是定位问题的基本工具。
资料出处 术语定义以本课正文为准；RAGAS 指标名与 RRF 公式为通用实现。
